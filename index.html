Mẹo: đặt điện thoại giữa bàn họp, để màn hình luôn sáng (app tự giữ sáng màn hình khi đang nghe). Âm thanh được gửi đi để chuyển thành chữ; file ghi âm chỉ được lưu khi bạn bật tùy chọn trong tab Cài đặt.
Các cuộc họp đã xử lý trên điện thoại này (tối đa 30 cuộc gần nhất).
1. Gemini (chuyển giọng nói → chữ và tóm tắt)
2. Google Docs (qua Apps Script của bạn)
Cần dán lại mã Apps Script bản mới. File khoảng 11 MB mỗi giờ họp, tối đa 30 MB mỗi file (khoảng 2 tiếng 40 phút).

API key và link chỉ lưu trên trình duyệt của điện thoại này, không gửi đi đâu khác ngoài Google.
